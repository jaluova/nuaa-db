### 多表自连接查询：至少选修两门课的学生

**问题回顾**：查询至少选修了两门课程的学生。

核心思路是将选课表 `SC` 使用两次（笛卡尔积），再加条件过滤：

```sql
-- 关键条件
SC1.Sno = SC2.Sno         -- 等值连接（同一学生）
SC1.Cno <> SC2.Cno        -- 不同课程
```

> [03:23] 加上 `SC1.Sno = SC2.Sno` 条件后，笛卡尔积被转化为等值连接，大量无用记录被过滤。

**无此条件**：笛卡尔积 -> 产生大量无用数据
**加上条件**：等值连接 -> 只保留同一学生的选课配对

### 易错题：查询没有选修1号课程的学生学号

```sql
-- 错误写法
SELECT Sno FROM SC WHERE Cno <> '1'
-- 这只会排除选修了1号课程的"记录"，而非"学生"
```

**正确思路**（三步法）：
1. 找出选修了1号课程的学生学号集合
2. 找出所有学生的学号集合
3. 两个集合做差（集合差运算）

在关系代数中用差（减）操作，在ALPHA语言中也类似——两个投影结果做集合差。

### ALPHA语言要点

- **存在量词**：从外层关系传递参数到内层判断，检查其他表中是否存在对应记录
  - 例如：查询选修了1号课程的学生姓名，从学生表取记录，用学号去选课表查是否存在选修1号课记录 [09:01]
- **全称量词**：对"所有"课程逐一检查是否存在选课记录
  - 例如：选修了所有课程的学生姓名 [11:21]

> [12:15] 存在量子和全称量子的共同模式：输出在一个关系中，但要传递参数到循环中查其他表，判断是否存在对应记录。

### 复杂示例：与计算机系人数相同的其他院系

| 步骤 | 说明 |
|------|------|
| 1 | 先算出计算机系的职工人数（`COUNT` + `WHERE sdept='CS'`） |
| 2 | 外层查询统计每个系的人数，条件：`dpid <> 'CS'` 且人数与计算机系相等 |
| 3 | 人数比较需在 `HAVING` 子句中完成 |

## SQL数据操作（DML）

### 一、插入数据（INSERT）

**基本语法**：`INSERT INTO 表名 VALUES (值1, 值2, ...)`

关键规则：
- 值的**个数**和**顺序**必须与表中属性列对应
- 可以不写属性名列名，但值必须与表结构严格匹配
- 对于不确定的值，可使用 `NULL`（如选课表中成绩暂无时赋空值）[17:45]

```sql
-- 带空值的插入
INSERT INTO SC(Sno, Cno, Grade) VALUES ('2021001', '1', NULL);
```

也可通过子查询实现整表插入：`INSERT INTO ... SELECT ...`

### 二、更新数据（UPDATE）

**基本语法**：`UPDATE 表名 SET 列名 = 表达式 WHERE 条件;`

```sql
-- 例1：将某学生年龄改为22
UPDATE Student SET Sage = 22 WHERE Sno = '2021001';

-- 例2：学生年龄统一加1
UPDATE Student SET Sage = Sage + 1;
```

> [19:55] 字段名本质上是一个**字段变量**，`SET` 左边只能是列名（变量），不能是表达式。`SET Sage+1 = ...` 这种写法是错误的。

- 字符串类型必须加单引号（如 `'CS'`）
- 数字类型不能加引号

**复杂更新**：将计算机系所有学生的成绩归零

```sql
UPDATE SC
SET Grade = 0
WHERE Sno IN (SELECT Sno FROM Student WHERE Sdept = 'CS');
```

或等价地使用连接子查询方式。

> [21:46] 执行机制：对SC表的每条记录逐条处理。取出当前记录的学号，到Student表中查该学生所在系，判断是否等于'CS'，满足条件则更新，不满足则跳过——逐条循环。

## SQL删除操作与完整性约束

### 三、删除数据（DELETE）

**基本语法**：`DELETE FROM 表名 WHERE 条件;`

注意：`DELETE` 后面没有列名（与 `UPDATE` 不同），因为删除操作针对的是整条记录。

> [35:48] 删除只能针对某一张表的记录，不能写多表连接删除。查询可以多表连接，删除不行。

**示例**：删除计算机系所有学生的选课记录

```sql
DELETE FROM SC
WHERE Sno IN (SELECT Sno FROM Student WHERE Sdept = 'CS');
```

**底层执行逻辑** [39:21-40:29]：

```
for i = 1 to n:            -- n = SC表记录数
    sno = SC[i].Sno         -- 取当前记录的学号
    if sno IN (子查询结果):  -- 判断是否属于计算机系
        删除 SC[i]          -- 满足则删除
    else:
        不操作              -- 不满足则跳过
```

> [44:10] 在实际应用系统中，**尽量不使用 IN 子句**——它的执行效率偏低。用连接子查询的方式通常更高效。两种写法的功能等价，但执行效率不同。

### 四、数据修改与完整性约束

修改/删除操作可能破坏三种完整性：

| 完整性类型 | 说明 | 示例 |
|-----------|------|------|
| **实体完整性** | 主码不能重复、不能为空 | 修改学生学号可能导致重复 |
| **参照完整性** | 外码取值必须在被参照关系中存在（或为空） | 修改选课表学号为Student表中不存在的值 |
| **用户定义完整性** | 自定义约束条件 | 姓名不能重名、成绩范围0-100 |

**级联策略** [28:28-28:58]：
- 策略一：**禁止修改**（有子记录时不允许改主表码值）
- 策略二：**级联更新/删除**（`CASCADE`）——修改主表，DBMS自动同步更新所有相关子表记录

> [33:44] 级联删除要**慎用**！误删一条学生记录，可能把该学生所有成绩、选课信息全部级联删除，后果严重。

**参照完整性双向分析**：

| 修改方向 | 影响 |
|---------|------|
| 修改**学生表**学号 | 受到实体完整性约束；同时触发对选课表的级联更新（参照完整性） |
| 修改**选课表**学号 | 受自身实体完整性约束（主码部分）；不能改为Student表中不存在的学号（参照完整性） |

### 五、空值（NULL）初识

- 数据库中的 `NULL` 是**特殊常量**，不是空字符串 `''`，也不是数字 `0`
- 高级语言中变量定义后内存中有一个随机值，但数据库的 NULL 是**有特殊标识的**
- 典型场景：选课表中的成绩字段——学生选了课但尚未考试/给分时赋 NULL
- 判断空值：`IS NULL` / `IS NOT NULL`（**不能用等号** `= NULL`）
- 赋值空值：直接写 `NULL`，**不能加引号**（`'NULL'` 是字符串）

> [47:36] 选课表成绩列不适合设定默认值——成绩可能为0分，无法区分"考了0分"和"未录入"。若真要设默认值，通常用一个不可能出现的负值。
