## DQL 概述与 SELECT 语句格式

数据库系统中约 **80% 的操作是查询**，更新操作仅占少部分。例如选课系统：学生大部分时间在浏览课程、查询课表，真正的更新只有最终点击"提交"按钮那一刻——将选课记录插入选课表。

SQL 查询的本质是关系代数的**选择（Selection）与投影（Projection）**的组合。最朴素的实现路径是：先将多张表做笛卡尔积（或等值连接）拼成一张大表，然后用条件过滤记录（选择），最后输出指定列（投影）。

SELECT 语句的完整语法结构：

| 子句 | 作用 | 对应关系代数 |
|------|------|------------|
| `SELECT [DISTINCT\|ALL] 目标表达式` | 投影：指定输出哪些列或表达式 | 投影 (π) |
| `FROM 表名/视图名` | 指定数据来源（可多表） | 笛卡尔积 / 连接 |
| `WHERE 条件表达式` | 选择：过滤记录（含连接条件） | 选择 (σ) |
| `GROUP BY 列名` | 按指定列分组 | — |
| `HAVING 条件表达式` | 对分组后的结果过滤 | — |
| `ORDER BY 列名 [ASC\|DESC]` | 排序输出 | — |
| `LIMIT n OFFSET m` | 分页：从第 m 条起取 n 条 | — |

> 在 WHERE 子句中，连接条件（如 `student.sno = sc.sno`）与查询条件（如 `grade > 60`）都写在一起，它们是多个条件的逻辑组合。这与关系代数中将笛卡尔积转化为等值连接时在 σ 条件中加入连接条件的思路完全一致。

## 目标表达式

SELECT 后面的内容本质上是一个**表达式**，而不只是列名。最简单的表达式可以是一个字段变量名（如 `sno`），也可以是由字段变量、常量、函数和算术运算符构成的复杂表达式。

| 表达式类型 | 示例 | 说明 |
|-----------|------|------|
| 字段变量 | `sno` | 最简单的表达式，输出表中原有列 |
| 算术表达式 | `2026 - sage` | 用当前年份减年龄得到出生年份 |
| 字符串常量 | `'学号:'` | 输出结果集中该列全为该常量值 |
| 函数表达式 | `LOWER(sdept)` | 将所在系转为小写字母输出 |
| 日期函数 | `YEAR(NOW()) - YEAR(birth)` | 动态计算年龄或证书年限 |

> `*` 代表所有列。当需要输出表中全部字段时，用 `SELECT * FROM student` 替代逐一列出所有列名，这在临时查询中非常方便。

### 列别名

查询结果集的表头默认使用原表达式文本（如 `2026 - sage`），不够直观。可通过 `AS` 或空格指定别名，使输出表头更友好。在应用开发中，数据库列名通常用英文命名，但展示给用户时必须显示中文别名。

## DISTINCT 与 ALL

查询结果中可能存在重复行，SQL 提供两种处理方式：

| 关键词 | 行为 | 默认 |
|--------|------|------|
| `ALL` | 保留所有重复行 | 是（省略时等价于 ALL） |
| `DISTINCT` | 去除重复行 | — |

典型场景：查询"选修了课程的学生学号"。从选课表投影学号，若一个学生选了 3 门课则会出现 3 条重复学号。加 `DISTINCT` 可去掉重复。同理，查询"所有被选修的课程编号"也需对课程编号去重。

## WHERE 子句：条件过滤

WHERE 后面是一个**逻辑表达式**。逻辑表达式可以用 `AND`、`OR`、`NOT` 连接多个子条件，构成复合条件。

### 比较运算符

| 运算符 | 含义 | 注意 |
|--------|------|------|
| `=` | 等于 | 字符串常量必须加**单引号**；若不加则是当作变量名 |
| `>` / `<` | 大于 / 小于 | — |
| `>=` / `<=` | 大于等于 / 小于等于 | 不能写成 `≥` / `≤`，也不能写成 `=>`，必须用 `>=`、`<=` |
| `<>` 或 `!=` | 不等于 | `!=` 非标准语法，但在多数 DBMS 中可用 |

> 字符串常量必须加单引号。`WHERE sdept = CS` 是错误的——`CS` 会被当作变量名而非字符串。正确写法是 `WHERE sdept = 'CS'`。判断依据：看该列建表时定义的数据类型是数值型还是字符串型。

### BETWEEN ... AND ...

`WHERE age BETWEEN 20 AND 23` 等价于 `WHERE age >= 20 AND age <= 23`（范围含边界）。若不记得 `BETWEEN` 语法，用 `AND` 连接两个比较条件即可替代。

### IN 与 NOT IN

`WHERE sdept IN ('CS', 'MA', 'IS')` 等价于多个 OR 条件串联：`WHERE sdept = 'CS' OR sdept = 'MA' OR sdept = 'IS'`。

> 从查询效率看，多个 OR 条件与 IN 的索引利用机制可能存在差异。涉及 `NOT IN` 时查询效率通常不高，尤其是在嵌套子查询中。

### LIKE：模糊查找

| 通配符 | 含义 |
|--------|------|
| `%`（百分号） | 匹配任意多个字符（含零个） |
| `_`（下划线） | 匹配**任意单个字符** |

**典型用例**：

| 需求 | WHERE 条件 | 说明 |
|------|-----------|------|
| 所有姓刘的学生 | `WHERE sname LIKE '刘%'` | 刘开头，后面任意 |
| 姓欧阳且全名三个汉字 | `WHERE sname LIKE '欧阳__'` | 一个汉字占两个字符（GBK），故用两个下划线 |
| 名字第二个字为"阳" | `WHERE sname LIKE '_阳%'` | 第一个字任意，第二个字为阳，后面任意 |
| 查 2002 级所有学生 | `WHERE sno LIKE '2002%'` | 学号以 2002 开头 |
| 不以"刘"开头 | `WHERE sname NOT LIKE '刘%'` | NOT 取反逻辑 |

> 一个汉字在计算机中占 2 个字节（字符），因此限制三个汉字的名字需用两个下划线（姓占两字符 + 名用两个下划线 = 四字符）。

### IS NULL / IS NOT NULL

数据库中的空值（NULL）**不能用等号判断**，必须用 `IS NULL` 或 `IS NOT NULL`。典型场景：选课时只插入了学号和课程编号，成绩列为空；老师查询"哪些学生还没有成绩"时条件为 `WHERE grade IS NULL`。

### 逻辑表达式注意事项

**常见错误**：`WHERE age >= 20 AND < 23` —— 第二个条件 `< 23` 不完整，AND 两边都必须是完整的逻辑表达式。正确写法：`WHERE age >= 20 AND age < 23`。

## ORDER BY：排序

- `ASC`：升序（默认）
- `DESC`：降序
- 可指定多个排序字段：`ORDER BY sdept ASC, sage DESC`
- 含 NULL 值的排序：不同 DBMS 规则不同，通常升序时 NULL 排最前，降序时 NULL 排最后

## GROUP BY 与 HAVING：分组与分组过滤

### 为什么需要分组

统计"每个学院的学生人数"，如果直接用 `COUNT(*)` 是对全表计数，无法区分学院。必须先将相同学院的学生**归为一组**，再对每组用聚集函数计数。

### 分组规则（重要）

| 规则 | 说明 |
|------|------|
| SELECT 后的非聚集字段 | 必须出现在 GROUP BY 中 |
| SELECT 后的聚集字段 | 若字段不在 GROUP BY 中，**必须用聚集函数包裹** |
| GROUP BY 后可跟表达式 | 如 `GROUP BY LEFT(sno, 4)` 按学号前 4 位（年级）分组 |

> 这条规则是考试和实际编程中的高频错误点：当使用了 `GROUP BY` 之后，SELECT 后面能直接出现的只有 GROUP BY 中列出的字段，其余字段必须搭配 `COUNT`、`SUM`、`AVG`、`MAX`、`MIN` 等聚集函数使用。

### HAVING vs WHERE

| 子句 | 作用对象 | 执行时机 |
|------|---------|---------|
| `WHERE` | **原始记录**（分组前） | 先过滤全表记录，再分组 |
| `HAVING` | **分组后的结果集** | 分组完成后，再对每组结果判定 |

> 经典错误：将"平均成绩大于 90 分的学生"的条件写在 WHERE 里。`WHERE AVG(grade) > 90` 意为"全体学生所有课程的平均成绩大于 90"，而非"每个学生的平均成绩大于 90"。正确应写在 HAVING 中，因为这是分组后的判定。

## LIMIT 与 OFFSET：分页

- `LIMIT n`：只返回前 n 条记录
- `LIMIT n OFFSET m`：跳过前 m 条，取后续 n 条（从第 m+1 条开始）

典型应用：网页分页显示。屏幕一次显示 10 行，第一页取 0~9 条，翻页后取 10~19 条，依此类推。
