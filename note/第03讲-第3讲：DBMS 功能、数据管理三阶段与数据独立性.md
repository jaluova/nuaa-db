## DBMS 的三大核心功能

以手工管理类比：画空表 → 填数据 → 归档管理。

| 功能 | 语言 | 全称 | 对应操作 |
|------|------|------|----------|
| 数据定义 | **DDL** | Data Definition Language | 创建空表，定义表结构（表名、列名、列类型、约束条件） |
| 数据操纵 | **DML** | Data Manipulation Language | 增(Insert)、删(Delete)、改(Update)、查(Select) |
| 数据控制 | **DCL** | Data Control Language | 安全授权、完整性保障、并发控制、故障恢复 |

> DDL 定义的是静态数据结构；DML 只包含四种基本操作；DCL 负责安全/完整性/恢复等。

### DDL 具体定义内容

- 表名称
- 表的列（几列、每列类型）
- 列的约束条件（如必填项，标 `*`）
- **表与表之间的数据约束关系**——这是文件系统做不到的

> 文件系统管理多个独立文件，文件之间的数据关系只能靠应用程序代码去解释和控制。DDL 可以在数据库层面定义这种关联。

## 构建数据库系统的三步选择

1. **选择 DBMS**：MySQL、Oracle、Access、甚至 Excel（功能强弱不同）
2. **选择开发语言**：C、C++、C#、Python、Java 等
3. **选择系统架构**：C/S 还是 B/S（不同语言能实现的架构不同，C 语言做不了 B/S）

## DBA：数据库管理员

- 每个 DBMS 都有一个超级用户，称为 **DBA**（Database Administrator）
- 类似 Windows 的 Administrator，可创建其他用户并授权
- 权限粒度：**谁能访问哪些数据对象** + **能做什么操作**（只读/可修改）

## 数据管理技术的三个发展阶段

### 第一阶段：人工管理

- 无外部存储设备、无操作系统、批处理方式
- 数据面向特定应用、不可共享、冗余度极大
- **数据与程序紧密绑定，不具有独立性**
- 数据结构无定义

### 第二阶段：文件系统

- 有磁盘存储 + 操作系统文件系统 + 实时处理
- C 语言文件操作：`fopen` → `fread`/`fwrite` → `fclose`
- 进步：数据可长期保存，记录内有结构
- 但仍有缺陷：
  - **文件之间相互独立，数据关联无法定义**
  - **数据的逻辑结构改变 → 必须修改应用程序**（不具备逻辑独立性）
  - 数据面向某一应用，共享性差，冗余度大
  - 记录结构靠程序定义和解释，数据只能是定长的

### 第三阶段：数据库系统

- DBMS 统一管理，结构化存储，可共享
- 支持文件间/表间的数据关联
- 具备数据独立性（逻辑 + 物理）

## 数据独立性：核心概念

### 逻辑独立性

**定义**：数据的逻辑结构发生改变时，应用程序可以保持不变。

以文件读写为例：
- 文件中数据按 `1 2 3` 顺序摆放，程序按位置读取
- 如果将顺序改为 `3 2 1`，程序必须修改才能得到正确结果
- 这说明**文件系统中数据与程序紧密耦合，不具备逻辑独立性**

解决方案思路（后文详述）：不按位置传参，而要按名称解释含义（如 `a=1, b=2, c=3`）

### 物理独立性

数据在磁盘上的物理存储方式改变时，不影响上层逻辑结构与应用程序。（后文详述）

## 关系型 (RDBMS) vs 非关系型 (NoSQL)

### 关系型数据库（本书重点）

- 数据模型：**二维表格**
- 代表：Oracle、MySQL、SQL Server、Access、PostgreSQL
- 目前主流，成熟稳定

### 非关系型数据库

- **数据模型不同**：不是二维表
- Key-Value 型（如 Redis）：`k → v` 简化为单一数据结构
- 文档型（如 MongoDB）：面向大文本/非结构化数据
- 时序型：面向实时监控等时序数据

> 数据模型决定了：数据表示方式 → 存储方式 → 查询使用方式，整套机制都不一样。

### 数据库产品演进趋势

- 2009年前后 NoSQL 兴起 → 近年又回归 NewSQL/分布式关系型
- 分布式数据库：将一个大数据库按区域/业务**分区**，部署在多台物理服务器上
  - 对用户透明（逻辑上仍是一台）
  - 解决负载均衡、提升并发处理能力
- 国产数据库市场份额快速上升，替代趋势明显

## 数据的三级映射

```
用户界面（子集视图）
    ↕
全局逻辑结构（完整表定义）
    ↕ DBMS
物理存储（磁盘二进制串）
    ↕ 操作系统
磁盘硬件
```

- 用户看到的课程列表只是数据库中课程表的**一个子集**
- DBMS 负责将逻辑表映射到物理二进制串
- DBMS 确定物理位置后，**向操作系统发出读写命令**（DBMS 不直接操作磁盘）
