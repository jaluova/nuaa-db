## 各章节重点

### 第一章：数据库系统概论

**三级模式两级映射**（最核心考点）：

| 层级 | 名称 | 说明 |
|------|------|------|
| 内模式 | 存储模式 | 数据在磁盘上的物理存储结构 |
| 模式 | 逻辑模式 | 全局逻辑结构，一个数据库**只有一个** |
| 外模式 | 子模式/用户模式 | 面向应用的局部逻辑视图，可有**多个**（对应视图） |

- 外模式-模式映射 → 保证**逻辑独立性**
- 模式-内模式映射 → 保证**物理独立性**

数据库三要素：数据结构、数据操作、完整性约束。
三种数据模型：层次模型、网状模型、关系模型。

### 第二章：关系数据库（约28分，全书最重）

#### 关系代数基本操作

- 选择 $\sigma$：按条件选行
- 投影 $\pi$：选列，**自动去重，重复行必须去掉**
- 连接 $\bowtie$：等值连接、自然连接（自动去掉重复列）、外连接
- 除法 $\div$：**最容易出错**，本质是集合的包含关系
- 集合运算：并 $\cup$、交 $\cap$、差 $-$

**除操作典型题**："查询选修了所有课程的学生学号"
1. $\pi_{Cno}(Course)$ — 所有课程编号
2. $\pi_{Sno, Cno}(SC)$ — 学号和课程编号
3. $\pi_{Sno, Cno}(SC) \div \pi_{Cno}(Course)$ — 做除操作
4. 如需姓名，最后与学生表连接

**外连接符号陷阱**（教材第51页）：自然连接符号与外连接"耳朵"标记不同，看错符号结果完全不同。

#### ALPHA语言（约10-20分，拉开差距的关键）

核心要素：
- 全程量词 $\forall$（"所有的"）
- 存在量词 $\exists$（"存在"）
- 逻辑蕴含

> 重点把教材上的例子看懂、理解透，然后迁移到不同场景。

### 第三章：SQL语言（约20分）

#### SQL三大分类

| 语言类型 | 分类 | 必会命令 |
|----------|------|----------|
| DDL（数据定义） | 定义结构 | CREATE TABLE / CREATE INDEX / CREATE VIEW |
| DML（数据操纵） | 操作数据 | SELECT / INSERT / UPDATE / DELETE |
| DCL（数据控制） | 权限控制 | GRANT / REVOKE |

> 创建索引、创建视图属于DDL——将"创建"当成DML是基本概念错误。DDL定义结构，DML操作数据。

#### 查询的三大技术

1. **连接查询**：多表JOIN，再做选择投影
2. **嵌套查询**（IN子查询）：子查询返回结果集，外层用IN判断
3. **分组统计**（GROUP BY + HAVING）：**WHERE对分组前记录筛选，HAVING对分组后结果筛选**

#### 重要知识点

- **聚集函数**：COUNT、SUM、AVG、MAX、MIN — 基础中的基础
- **日期函数**：如YEAR(出生日期)提取年份
- **派生表查询**（教材第107页）：FROM中使用子查询结果作为临时表
- **递归查询**（WITH RECURSIVE / CTE）：可能用于拉开区分度
- **NULL值处理**（教材第111页）：IS NULL / IS NOT NULL，统计时必须排除NULL
- **视图创建**：`CREATE VIEW 视图名 AS (SELECT语句);`

> **铁律**：SQL关键词写错，整题0分。结构大体正确但有小毛病，通常还能拿50%以上分数。

### 第五章：数据库完整性

三类完整性：

| 完整性类型 | 含义 | 定义方式 |

### 第六章：关系数据理论（20分以上，全书核心）

#### 标准解题链路

$\text{属性闭包 } X^+ \xrightarrow{X^+ = U} \text{候选码} \rightarrow \text{极小函数依赖集 } F_{min} \rightarrow \text{范式判定} \rightarrow \text{模式分解}$

#### 第一步：属性闭包计算
**所有后续步骤的根基。** 是固定套路，必须会算。

#### 第二步：候选码求法（属性分类法）

| 属性出现位置 | 在候选码中？ | 策略 |
|-------------|------------|------|
| 只在左部出现 | **必在** | 纳入基本集 |
| 只在右部出现 | **不在** | 排除 |
| 左右都出现 | **可能**在 | 逐一尝试加入 |
| 左右都不出现 | **必在** | 必加入基本集 |

若 $X^+ = U$，则X为超码。通过组合尝试确定最小候选码。

#### 第三步：范式判定

| 范式 | 判定条件 |
|------|----------|
| 1NF | 所有属性不可再分（自然满足） |
| 2NF | 无非主属性对码的**部分函数依赖** |
| 3NF | 无非主属性对码的**传递函数依赖** + 满足2NF |
| BCNF | 所有决定因素都包含码 |

> 往年证明题："任何二元关系至少属于第几范式" → 答案：至少3NF。

#### 第四步：模式分解

将传递依赖链一拆为二。证明过程不需要掌握，只需会基本分解操作。

### 第九章：物理存储与B+树（约15分，新增章节但必考）

#### B+树索引动态构建（核心考点）

根据数据输入**顺序**动态构建。节点分裂时保持**均匀分布**——不是简单让新数据独占新节点，而是重新分配键值使两边均衡。

**查询代价估算**：
- **主键索引查询**：代价 = B+树层数（根到叶的块数） + 1次数据块读取
- **非主键索引查询**：需额外考虑同名人数和分布

> 数据块本身至少读一次，千万别漏了。

定长记录/变长记录的基本组织方式也需了解。

### 第十章：查询优化（约15分）

#### 代数优化
1. 将查询画成语法树
2. 利用等价变换规则（选择下推、投影下推）调整操作次序
3. 得到优化后的关系代数表达

#### 物理优化：三种连接算法

| 连接算法 | 说明 |
|----------|------|
| 嵌套循环连接 | 教材第308页有完整块读写数公式，往年考过计算 |
| 排序归并连接 | 外表+内表各读一次 + 排序代价（有专门公式） |
| 哈希连接 | 了解基本思路 |

排序归并连接代价 = 外表块数 + 内表块数 + 排序代价（若两端未排序）

### 第十一章：恢复与并发控制（约5-8分）

#### 恢复技术
- 事务故障类型
- 基于检查点的恢复
- REDO与UNDO判定（给定检查点和故障时间点，判断每个事务做REDO还是UNDO）

#### 并发控制
- **冲突可串行化**判定：能否通过交换非冲突操作转化为串行
- **可串行化**判定：调度是否正确
- 两段锁协议
- 封锁粒度与锁类型

> 可串行化问"调度是否正确"；冲突可串行化问"能否通过交换非冲突操作转化为串行"。冲突可串行化成立则调度一定正确。
