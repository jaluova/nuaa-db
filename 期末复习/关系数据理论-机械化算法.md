# 关系数据理论 · 机械化算法速查

> 属性数少（≤8），暴力穷举也完全可行。以下算法可无脑验证手算结果。

---

## 一、属性闭包 $X_F^+$

> 给定 $X$ 和依赖集 $F$，求所有由 $X$ 决定的属性。**所有后续步骤的根基。**

```
result = X
循环扫描 F 中每条 FD Y→Z:
    若 Y ⊆ result，则 result = result ∪ Z
直到 result 不再变化 → 返回 result
```

手算：列出当前能推出的属性，逐条扫描依赖，直到不再扩张。

---

## 二、候选码（属性分类法）

**口诀**：L类+N类必在；R类不在；LR类逐个试。

| 类 | 出现位置 | 结论 |
|----|----------|------|
| L | 仅左部 | **必在**候选码 |
| R | 仅右部 | **不在** |
| LR | 左右都出现 | 逐个尝试加入 |
| N | 都不出现 | **必在** |

**步骤**：
1. core = L ∪ N
2. 若 core⁺ = U → core 是唯一候选码
3. 否则从 LR 中逐个（从少到多）添加属性，测试闭包是否等于 U
4. 找到后验证极小性：去掉子集中任一属性，闭包不再等于 U

**示例**：$U=ABCD$, $F=\{AB \rightarrow C, C \rightarrow D, D \rightarrow B\}$

- L = {A}，LR = {B,C,D}，core = {A}，A⁺ = A ≠ U
- (AB)⁺ = ABCD = U ✓，极小 ✓
- (AC)⁺ = ACBD = U ✓，极小 ✓
- (AD)⁺ = ADBC = U ✓，极小 ✓
- **候选码：AB, AC, AD**（全是主属性）

---

## 三、范式判定

**前提**：先求出所有候选码，标出主属性（出现在任一候选码中的属性）。

| 范式 | 判据 | 本质 |
|------|------|------|
| 2NF | 不存在非主属性对候选码**真子集**的函数依赖 | 消除部分依赖 |
| 3NF | 不存在非主属性对候选码的**传递依赖** | 消除传递依赖 |
| BCNF | 每个非平凡 FD 的决定因素都是超键 | 消除所有"非超键决定" |

**判定流程**（从高到低）：
1. **BCNF**：遍历 F 中每条 X→Y，若 X⁺ ≠ U → 不满足
2. **3NF**：若非主属性被非超键决定 → 不满足（传递依赖）
3. **2NF**：若非主属性依赖于候选码的真子集 → 不满足（部分依赖）

> 往年题："任何二元关系至少属于第几范式" → 至少 3NF。

## 四、最小依赖集 $F_{min}$

```
Function MinCover(F):
    // ① 右部单一化
    F1 = ∅
    For each X → Y in F:
        For each A in Y:
            F1.add(X → A)

    // ② 左部极小化 (对每个 FD 的左边逐个属性试删)
    For each X → A in F1:
        For each B in X:
            If A ∈ Closure(X - {B}, F1):       // 在当前 F1 下求闭包
                F1.replace(X → A, (X - {B}) → A)
                If 新 FD 已存在: F1.remove(X → A)

    // ③ 删除冗余依赖 (逐条试删，用不含自身的剩余 FD)
    For each X → A in F1:
        If A ∈ Closure(X, F1 - {X → A}):       // 注意：不含自身
            F1.remove(X → A)

    Return F1
```

**示例**：$F=\{A \to C,\; C \to A,\; B \to AC,\; D \to AC,\; BD \to A\}$

① → $\{A \to C, C \to A, B \to A, B \to C, D \to A, D \to C, BD \to A\}$

② $BD \to A$：$(BD - \{B\})^+ = D^+ = \{D, A, C\}$，含 $A$ → B 多余 → 换成 $D \to A$（已有，删）。其余 FD 左边已单属性，跳过。

③ $B \to C$：在剩余 FD 下 $B^+ = \{B, A, C\}$，含 $C$ → 删。$D \to C$：$D^+ = \{D, A, C\}$，含 $C$ → 删。其余保留。

$$F_{min} = \{A \to C,\; C \to A,\; B \to A,\; D \to A\}$$
