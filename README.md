# 数据库原理复习资料

南京航空航天大学《数据库原理》课程（周良老师）的学习笔记与期末复习资料，基于《数据库系统概论》（第六版，王珊）。

## 目录结构

```
.
├── note/                   # 课堂笔记（47 讲）
│   ├── 第01讲 ~ 第47讲      # 随堂笔记，覆盖课程全部内容
│   └── ...
├── 期末复习/                 # 期末复习专题
│   ├── 考试重点整理.md        # 分值分布与重点章节
│   ├── 关系代数与关系运算.md   # ALPHA 语言、关系代数
│   ├── 关系数据理论-机械化算法.md # 候选码、范式判定步骤
│   ├── 范式直觉理解.md        # 范式概念讲解
│   ├── 试卷/                 # 往年真题整理
│   └── 模拟卷/               # 模拟试卷
├── code/                    # SQL 代码片段

```

## 笔记内容概览

| 模块 | 章节范围 | 主要内容 |
|------|----------|----------|
| 基础篇 | 第1–7讲 | 数据管理演进、三级模式、数据模型、E-R 图 |
| 关系模型 | 第8–11讲 | 关系代数、关系演算、完整性约束、查询优化 |
| SQL 语言 | 第12–19讲 | DDL/DQL/DML/DCL、嵌套查询、视图、空值处理 |
| 数据库安全 | 第20–21讲 | 访问控制、授权与回收 |
| 触发器与完整性 | 第22讲 | 触发器语法与应用 |
| 关系数据理论 | 第23–29讲 | 函数依赖、范式（1NF–BCNF）、Armstrong 公理、模式分解 |
| 数据库设计 | 第30–32讲 | DFD 数据流图、E-R 设计策略、ER 图转关系模式 |
| 存储与索引 | 第33–37讲 | 游标、存储过程、B+ 树索引、位图索引 |
| 查询优化 | 第37–38讲 | 代数优化、查询树等价变换 |
| 事务与恢复 | 第39–42讲 | ACID、故障类型、日志与 UNDO/REDO |
| 并发控制 | 第43–46讲 | 封锁、活锁死锁、可串行化、两段锁协议、意向锁 |
| 复习串讲 | 第47–48讲 | 全书复习与考试策略 |

## 期末重点

根据 2026 年考试分值分布，**三大高分模块**：

1. **关系代数 + ALPHA 语言**（约 28 分）
2. **SQL 语言**（约 20 分）
3. **关系数据理论 / 范式**（20 分以上）

详细重点见 `期末复习/考试重点整理.md`。
